# PROJECT: BETTER-SIMPLE-IMAGE-UPLOAD

> LANGUAGE: Rust | CATEGORY: Image Storage / Image Processors

## LIBRARIES

- axum
- tokio

## DESCRIPTION

A blazingly fast, minimal image upload service built in Rust.
Handles multipart uploads, on-the-fly image processing, and
efficient storage — designed to be a drop-in backend for any
project that needs images without the bloat.

No S3 required. No vendor lock-in. Just raw performance.

## FEATURES

- Multipart upload endpoint via axum
- Async I/O through tokio runtime
- Image format conversion and resizing on ingest
- Local filesystem storage with clean path routing

# PROJECT: CHAT-LAYER-UI

> LANGUAGE: TypeScript | CATEGORY: Chat Playground / AI Chat

## LIBRARIES

- react
- vite

## DESCRIPTION

A modular, provider-agnostic chat interface for experimenting
with AI models. Swap backends, tweak prompts, compare outputs —
all within a clean and hackable frontend layer.

Built for tinkerers who want to poke at language models without
wrestling a bloated SDK.

## FEATURES

- Multi-provider support (OpenAI-compatible endpoints)
- Configurable system prompts and model parameters
- Conversation history with session persistence
- Minimal UI with focus on readability and speed

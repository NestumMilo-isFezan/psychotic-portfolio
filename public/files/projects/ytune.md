# PROJECT: YTUNE

> LANGUAGE: Python | CATEGORY: Music

## LIBRARIES

- yt-dlp
- textual

## DESCRIPTION

A terminal-native music player powered by yt-dlp and rendered
with a retro TUI built in Textual. Search, queue, and listen
without ever leaving the command line.

The aesthetic is the point. So is the music.

## FEATURES

- Search and stream audio via yt-dlp
- Full TUI interface with keyboard navigation (Textual)
- Queue management and playback controls in the terminal
- Minimal dependencies, maximum vibe
